# Opponent Pass-Rush Brief — The Film Room

**[Open the live demo](https://production.dq0yh80z3cam4.amplifyapp.com/)** · Hosted on AWS Amplify in London (`eu-west-2`).

An interactive scouting tool for offensive-line coaches preparing to protect their quarterback.
Using NFL tracking and PFF scouting data from Weeks 1–8 of 2021, it covers 32 defenses and 7,767 eligible passing plays.
Select an opponent and game situation to explore pressure sources, five-plus-rusher frequency and pass-coverage tendencies, with sample sizes and links to supporting plays.
Animated replays highlight key players, movement paths, recorded timing and outcomes to help coaches decide what to review.
These historical patterns do not establish cause and effect, and pressure credit alone does not identify a blocker failure.

**Run locally:** With Node.js 18+, run `npm start` from this folder and open http://127.0.0.1:4173. Processed data are included. Run `npm test` for automated checks.
